# Acme Portal (demo project)

A made-up project for LazySpec: its specifications and changes are what the developer guide's screenshots
show, and what `docs/examples/` was exported from. Nothing here is a real product or client.

```
cd examples\acme-portal
lazyspec                                   # the UI
lazyspec -Export Pdf -IncludeChanges -ClientFriendly
lazyspec -Export Word -Item 01-add-user-signup -ClientFriendly
```
